## 配套的两个工具

**`发给同学/语料编辑器.html`**
单文件网页工具，**双击即用，不需要安装任何东西**。组员用它写训练语料，
导出的 JSONL 可以直接喂给训练脚本。附带草稿自动保存。

**`工具/合并语料.py`**
多人交回来的语料格式一定会乱（role 写错、答得太短、最后一句停在提问上、JSON 语法错、重复……）。
这个脚本把脏数据挡住，并报出「第几行、为什么」，可以直接转给对应的人改。

```
文件                              合格   不合格   字数   备注
A-张三.jsonl                         2      0     59
B-李四.jsonl                         1      5      5   见下
        └─ 第 3 行：第 1 轮的 role 是 'USER'（只能是 user/assistant/system）
        └─ 第 5 行：没有 assistant 轮
```
